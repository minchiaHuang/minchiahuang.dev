# AGENTS.md — minchiahuang.dev

Min-Chia (Tommy) Huang's public portfolio: a desk + retro CRT scene generated by a Blender script, with a
small React "OS" on the monitor. Deployed on Cloudflare Pages.

## Layout
- `app/` — outer three.js scene (Vite, TypeScript). Builds to `app/dist/`, the deploy output.
- `os/` — the OS on the monitor (React). Builds into `app/public/os/` (gitignored), served at `/os/`.
- `blender/` — `scene_v2.py` builds and bakes the scene; output in `blender/out/v2/` (kept in git).
  `blender/preview/` is a Vite page that shows the bake output.
- `tools/` — build and check scripts. `bin/verify.sh` — the one check that decides "done".

## Commands
- Verify everything: `bash bin/verify.sh`
- Unit tests: `node --test <files>` (Node 24+ runs `.ts` directly; no test framework)
- Full bake (~9 min): `/Applications/Blender.app/Contents/MacOS/Blender -b -P blender/scene_v2.py`
- Quick bake (~45 s): `BAKE_SIZE=1024 BAKE_SAMPLES=64 /Applications/Blender.app/Contents/MacOS/Blender -b -P blender/scene_v2.py`
- Preview images: `bash tools/preview-shots.sh <out-dir>` (headless Chrome; the Orca browser has no WebGL)
- DOS games (not in git): `bash tools/fetch-dos-games.sh`

## Rules
- Every file under `app/public/` and `blender/assets/` needs a `CREDITS.md` entry (path, source,
  licence). Only CC0, own work, or licences listed in `CREDITS.md`.
- Never copy files from other portfolio sites or from the private 3d-portfolio-lab repo's
  `app/public/`. Never add that repo as a remote.
- Edit only your own section of `CREDITS.md`.
- Do not change `bin/verify.sh` unless the task says so; tools turn its steps on by existing.
- New npm packages need the user's approval first.
- `rm -rf` and `git branch -D` are blocked; scripts leave temp files under `$TMPDIR`.
- Code, comments, commits and branch names in English. Commits: `<type>(<scope>): <description>`.
