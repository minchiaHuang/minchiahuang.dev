# Credits

Every file under app/public/ and blender/assets/ is listed here with its source and licence.
`bash tools/clean-check.sh` (run by `bin/verify.sh`) fails when a file has no entry. A path that
ends in a slash covers every file below it, so backtick a directory only in its own table row.

| Path | What | Source | Licence |

mug, floppy disks, notepad, wall print, potted plant) is geometry generated by
