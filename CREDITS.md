# Credits

Every file under app/public/ and blender/assets/ is listed here with its source and licence.
`bash tools/clean-check.sh` (run by `bin/verify.sh`) fails when a file has no entry. A path that
ends in a slash covers every file below it, so backtick a directory only in its own table row.

## 3D scene (blender/)

| Path | What | Source | Licence |
|---|---|---|---|
| `blender/assets/kenney/` | Furniture Kit 2.0 models and Kenney's `License.txt`. Not used by the current `scene_v2.py`. | https://kenney.nl/assets/furniture-kit | CC0 1.0 |

Everything in the scene (room, shared table, chairs, hoodies, pendant lamp, the egg-shaped
all-in-one computer with its keyboard and puck mouse, laptops and their plain-shape stickers,
power strip, cables, cans, pizza boxes, mug, notebook, whiteboard sketch) is geometry generated by
`blender/scene_v2.py`, with no logos or brand marks. `blender/out/v2/` is that script's output.
